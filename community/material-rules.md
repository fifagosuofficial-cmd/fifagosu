# 강화 재료 최저가 엔진: 공식 규칙 데이터 연결 필요
공식 출처: https://fconline.nexon.com/DataCenter/PlayerGrow
공식 공지: https://fconline.nexon.com/news/notice/view?n4ArticleSN=5106
공식 게이지 도우미의 동적 수치 응답을 검증해야 한다. 현재 공개 페이지 텍스트에서는 개별 포인트를 확인하지 못했으므로 규칙값을 넣지 않았다.
data 브랜치의 data/rules/boost_points.json에 검증 후 입력하는 계약:
- schema: 1, verified: true, source: 공식 도우미 URL(위), fullPoints: 풀게이지 기준 양의 정수
- rows: [{grade: 현재 강화단계(1..12), targetOvr: 대상 카드의 현재 강화 OVR, materials: [[재료의 강화 반영 OVR, 검증된 포인트], ...]}]
- 실제 공식 도우미에서 단일 재료의 게이지 기여량 및 여러 장 조합을 비교 검증. 반올림 표시를 정확한 내부 포인트로 가정하지 않는다. 올림으로 100% 처리하지 않는다. 이벤트 부스트나 동일 선수 효과는 제외.
- 전체 규칙에 대한 검증이 없으면 해당 단계 또는 재료를 제외한다. 현재 계산되는 최저가는 검증된 OVR 후보와 수집 시세 범위 내 최저이며 실제 구매 수량/거래 가능 여부는 별도 확인.
- 빌드는 data/list 200개 샤드에서 정확한 단계별 시세를 읽어 OVR별 저렴한 서로 다른 선수 두 명만 보관한다(동일 선수 제외를 지원). 같은 재료 카드 여러 장 구매 가능하다고 가정.
- 기존 같은 OVR 최저가×5 추정 로직은 제거. 미확인 시 자동 비용 미표시. 수동 재료비 입력 및 재료비 제외 순위 유지.
