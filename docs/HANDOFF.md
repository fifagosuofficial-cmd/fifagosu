## 11-22 완료 내역 (오래된 것 → 최근)
1. **시뮬 개편**: 판매 조건 바 + 4탭(강화 효율·강화 시뮬·팩 오픈·현질 효율). 현질 효율은 FC INFO와 ±5% 이내. 강화 손익 누적, 재료비 BP 입력(한글 단위), '추정값' 안내.
2. **패키지 구성품**: 상점 상세 구성품 → 확률표 연결(교환권 제외).
3. **선수 거래소** `/trade/`: 선수 검색·판매/구매희망가·시세 대비 %, 비번으로 완료·삭제. D1 연결 완료.
4. **전적 진단 개편**: 상단 요약(막대 그래프 + 마우스 올리면 상대·스코어 말풍선), '피파고수의 한마디', 컴팩트 카드. 감독모드는 선수별 기록이 첫 화면(승률 포함). 랭커 평균 70% 미만 공격·수비 지표는 빨간 숫자 + `!`.
5. **킥킥**: 이름 '킥킥 · 내가 선수라면?', 탭에서 링크 안 열리던 버그 수정. 리뉴얼(직원 토론 → 마스터플랜, `docs/plan/2026-11-22-킥킥리뉴얼-*.md`)로 허브 8종, 공유 버튼 3개, 결과 링크 + 카톡 미리보기, og 이미지. **이름 생성기는 대표 반려로 내림**(코드는 `APPS.push` 주석 처리로 보관).
6. **진행 중 이벤트** 4개만 보이던 문제 해결(수집 1~5페이지, 홈 4개 + '모두 보기'), 이벤트 막대가 박스 밖으로 삐져나오던 CSS 충돌 수정.
7. **소식/뉴스 분리**, 게임 가이드 급여·이적시장은 숫자 없이 설명 위주, 모바일·태블릿 메뉴 줄바꿈(가로 스크롤 없음).
8. **메뉴 이름**: 시뮬 → 강화/현질 효율, 선수장터 → 선수 거래소. 전적 진단 메뉴는 항상 강조(`a.core`).
9. **전적 진단 평점 비교 + 대체 추천**
   - 평점이 챔피언스 같은 포지션 평균보다 0.1 이상 낮으면 빨간 숫자 + `!`(3경기 이상). 기준은 `data/rating.json`.
   - 넥슨 랭커 통계엔 평점이 없고 전체 매치 목록 API는 우리 키로 403 → `rating.py`가 높은 등급 상대를 따라가는 '눈덩이 표본'으로 매일 수집(시드 Lampard8).
   - 평점·공격/수비가 낮은 선수 이름 옆 `!` 버튼 → 대체 추천 최대 5명.
     - **팀컬러 유지**: 선발 11명의 클럽 경력·국가로 활성 팀컬러 계산(lampard8 = 첼시 11명 4단계, 잉글랜드 6명). 바꾸는 선수가 속한 가장 큰 팀컬러 소속 선수만 추천.
     - **강화 물결 유지**: 금빛이면 8강 이상, 백금빛이면 11강 이상 기준.
     - **가격**: 기본은 같은 강화 시세 0.6~1.6배(없으면 0.4~2.5배로 넓힘). **예산 수정** 버튼으로 금액 입력 시 그 금액 이하 카드만.
     - 급여·급여 차이, OVR, 신규 특성, 키/몸무게, 공유 팀컬러 칩 표시. 누르면 선수 정보창(그 강화 단계).
10. **관계 팀컬러**(선수 정보창): 이름의 시즌(예: 25-26)과 카드의 클럽 재적 기간을 맞춰 실제 해당 시즌만 표시. 연령별 대표(U-20 등)는 그 무렵 데뷔한 선수만.
