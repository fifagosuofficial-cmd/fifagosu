## ③ 공통 개선

### 3-1. 결과 카드 규격 (모든 콘텐츠 공통)
- 크기: 1080×1920(9:16). 위·아래 250px은 인스타 UI 영역이라 비움(현행 유지).
- 카드 안 요소는 **최대 5개**, 이 순서로:
  1. 머리말 (작게): "윤재의 축구 별명" / "나의 감독 유형"
  2. **큰 제목 1줄**: 16자 이내(이름 포함). 카드에서 제일 커야 함
  3. **한 줄 근거/설명**: 30자 이내. "왜 이 결과?"가 보이게
  4. 칩 3개: `#지각확정` 같이 답변에서 나온 것만
  5. 하단 고정: "너는 뭐 나와? → fifagosu.pages.dev/fun"
- 기사·응원가·중계·풀네임·다른 나라 버전 같은 '덤 조각'은 카드에서 뺌. 필요하면 카드 아래 HTML에만 표시.
- 문구 2문장 이상, 5줄 박스 금지.

### 3-2. 공유 장치 (결과 화면 버튼 3개로 통일)
| 버튼 | 동작 | 이번에? |
|---|---|---|
| ① 이미지 저장/공유 (스토리용) | 현행 `saveCanvas`(Web Share 파일 → 실패 시 다운로드) 유지 | 유지 |
| ② **결과 링크 복사** | 결과 URL을 클립보드에 복사 + "복사됐어요! 카톡방에 붙여넣어 보세요" 토스트 | **필수** |
| ③ 링크로 공유 | `navigator.share({title, text, url})` — 파일 공유가 안 되는 기기용. 미지원이면 ②로 대체 | **필수** |
| (④ 카톡 공유 버튼) | 카카오 JS SDK — 앱키 필요 | 대표 결정 후 다음에 |

- 공유 문구 형식: `"윤재의 축구 별명은 '후반 재투입 윤재' ㅋㅋ 너는 뭐 나와?"` + 결과 URL. (현재는 항상 `/fun/`만 붙음 → 결과 URL로 교체)
- 인스타는 "이미지 저장 → 스토리 업로드 → 링크 스티커"가 현실적인 경로. 결과 화면에 작게 안내 문구 한 줄.

### 3-3. 결과 URL 바이럴 루프
- **이번(정적, Functions 없이)**: `/fun/?r=앱id&...` 쿼리 방식. 페이지가 열리면 `route()`가 쿼리를 읽어 결과 카드를 바로 보여줌.
  - 이름 생성기: `/fun/?r=name&n=윤재&a=2130021130` (이름 + 문항별 선택 번호 10자리)
  - 궁합: `/fun/?r=duo&a=윤재&b=민수`
  - 유형형: `/fun/?r=manager&k=bus`
  - 결과는 이미 시드(`hashStr`+`rng`) 구조라 저장 없이 재현 가능.
- 친구가 링크로 들어오면 결과 카드 아래 큰 버튼 2개: **"나도 해보기"**, (궁합) **"나랑 OO 궁합 보기"**.
- 잘못된 쿼리(문항 수 불일치, 이름 비어 있음)는 허브로 조용히 이동.
- 이름 입력은 최대 6자, 입력창에 "닉네임도 OK (링크에 이름이 보여요)" 안내.
- **다음(대표 확인 후)**: Cloudflare Pages Functions로 결과별 og:title 동적 삽입("윤재의 축구 별명: 후반 재투입 윤재"). 카톡 크롤러는 JS를 안 돌려서 이건 서버 쪽이 필요해요. 무료 한도 안이지만 `functions/`·`_routes.json` 구조가 바뀌는 일이라 대표 확인 대상으로 둠(⑦).

### 3-4. og 이미지 / 메타 (필수)
- `fun/og/default.png` 1200×630 1장 제작(킥킥 로고 + "이름 넣고 10초, 내 축구 별명은?"). 기존 캔버스 코드로 한 번 그려서 PNG로 저장하면 됨.
- `<head>`에 추가/수정: `og:image`(절대 URL), `og:url`, `og:title`("킥킥 · 내 이름으로 만드는 축구 별명"), `og:description`("질문 10개 답하면 너다운 별명이 나와요. 친구 것도 보기"), `twitter:card=summary_large_image`.
- 배포 후 카카오 공유 디버거에서 캐시 초기화(QA 체크 항목).
- 콘텐츠별·결과별 og 이미지(유형형 미리 생성)는 나중에.

### 3-5. 허브 화면
- 맨 위 히어로 카드 1개: **"NEW 내 이름 축구 별명"** (가장 큰 카드, 바로 이름 입력창)
- 그 아래 2열 그리드, 공유력 순서: 내가 축구선수라면? → 투톱 궁합 → 닮은 구단 → 팬 유형 → 감독 유형 → 밸런스 게임 → 흐린 사진 퀴즈 → 내 몸값
- 각 카드 부제는 "소요 시간 + 한 줄" (예: "1분 · 질문 10개, 너다운 별명")
- "선수 873명" 같은 하드코딩 숫자 삭제
- 광고 승인 전 빈 박스("광고 자리") 숨김. 광고 자리는 **결과 카드 아래 · 공유 버튼 아래**로 고정(공유 버튼보다 위에 두지 않음 — 공유가 수익의 원천)

## ④ 이름 생성기 상세 설계

### 4-1. 흐름
`introView`(이름 1칸) → `runQuiz`(질문 10개, 4지선다) → 결과 카드 → 결과 URL.
league/price가 이미 쓰는 "이름 입력 + runQuiz" 패턴 그대로. 엔진 수정 최소.

### 4-2. 이름 처리 규칙
| 입력 | 처리 | 예 |
|---|---|---|
| 3글자 한글, 첫 글자가 성씨 목록에 있음 | 뒤 2글자 = 이름(N) | 박도윤 → 도윤 |
| 4글자, 앞 2글자가 복성(남궁·황보·제갈·선우·독고·사공·서문) | 뒤 2글자 | 남궁민수 → 민수 |
| 2글자 | 그대로 이름으로 봄(윤재, 지훈). 외자(김산)도 그대로 | 윤재 → 윤재 |
| 4글자 이상(복성 아님), 1글자 | 그대로 | |
| 한글 아님(영문 등) | 그대로, 글자 규칙 건너뛰고 '상황형'만 사용 | Tom |

- 성씨 목록: 상위 60개 정도면 충분(김이박최정강조윤장임한오서신권황안송류전홍고문양손배백허유남심노하곽성차주우구민진나지엄채원천방공현함변염여추도소석선설마길연위표명기반왕금옥육인맹제모탁국어은편용예봉경사부).
- 변수: `N`(이름), `F`(첫 글자), `L`(끝 글자), `J(L)`(받침 유무, 기존 `hasJong`).
- 조사: 받침 있으면 "지훈이는/지훈이랑/지훈아", 없으면 "윤재는/윤재랑/윤재야". 문구 안에서 부를 때는 애칭형(지훈이) 사용 가능.
- 결과 화면에 "OO(으)로 불러요" 작게 표시 → 성 처리가 틀렸을 때 사용자가 알 수 있게(수정 버튼은 나중에).

- 근거 조각 예: 1-C "7시 12분 도착", 3-C "하프타임 취침", 6-B "10분 만에 방전", 8-A "유니폼 못 참음".

### 4-4. 별명 조합 규칙
**1단계 — 태그 집계**: 태그별 점수 합산 → 1위(T1), 2위(T2). 동점은 시드 랜덤(`rng(hashStr(N+'|'+답변코드))`).

**2단계 — 이름 글자 매칭(끝 글자 L 우선, 없으면 첫 글자 F)**: 글자 사전에서 그 글자로 시작하는 축구 단어를 찾되, **T1 또는 T2와 태그가 맞는 단어만** 채택. (이름과 답변 둘 다에 걸리게 하는 핵심 장치)

글자 사전 초안 (단어 [어울리는 태그]) — 이번엔 30글자 내외, 나머지는 다음에 확장:

| 수 | 수비[칼같음], 수문장[칼같음], 수중전[야식(?)] → 수문장 위주 |

**3단계 — 형식 선택**
- **글자형**(2단계 성공 시, 우선): `[T 수식어] + [글자 단어] + N` 또는 `[글자 단어] 장인/전문 + N`
  - 예: 윤재(지각·체력) → **"후반 재투입 윤재"**
- **상황형**(글자 매칭 실패, 영문 이름): `[T1 수식어] + N` + 부제에 T2
  - 태그별 수식어(각 3개 이상 준비, 이 표는 1~2개씩 예시):

| 태그 | 수식어 예 | 한 줄 근거 톤 |
|---|---|---|
| 지각 | 후반 12분, 인저리 타임 입장 | 경기 시작하고 나타나는 타입 |
| 칼같음 | 킥오프 5분 전, 정규시간 엄수 | 휘슬보다 먼저 와 있음 |
| 읽씹 | 원터치 차단, 연락 오프사이드 | 패스(톡)는 받는데 안 돌려줌 |
| 수다 | 주장 완장, 경기 후 인터뷰 장인 | 단톡방 점유율 70% |
| 해축 | 새벽 4시, 알람 3개 | 해 뜨기 전 이미 90분 봄 |
| 대충 | 하이라이트 3분, 벤치 평화주의 | 결과만 알면 됨 |
| 체력 | 전반 15분, 숨 고르기 중 | 의욕 100, 체력 15 |
| 승부욕 | 한 판 더, 연장전 신청 | 질 때까지가 아니라 이길 때까지 |
| 핑계 | 컨디션 난조, 부상 의심 | 사유서는 늘 준비됨 |
| 야식 | 하프타임 야식, 새벽 라면 | 경기보다 메뉴 결정이 빠름 |
| 주인공 | 세리머니 먼저, 카메라 앞 | 골보다 세리머니 연습이 먼저 |
| 지갑 | 유니폼 3벌, 이적시장 큰손 | 굿즈 앞에서 수비 0점 |

- **모순 보너스**: T1·T2가 반대 성격(승부욕+체력, 칼같음+지갑, 핑계+승부욕)이면 근거 문구를 "~인데 ~" 반전형으로. 반전이 제일 웃겨요.

**4단계 — 근거 한 줄(필수)**: `'{글자}' + {근거 조각1} + {근거 조각2}` 형식, 40자 이내.
- 예: "끝 글자 '재' + 7시 12분 도착 + 10분 만에 방전"

**5단계 — 등번호(number 흡수)**: T1 → 번호 표(근거 있는 번호). 예: 지각 99번("늦게 와서 남은 번호"), 칼같음 1번, 수다 10번("말로 경기 조율"), 해축 4번("새벽 4시"), 체력 15번("15분 출전"), 승부욕 7번, 주인공 9번, 지갑 23번, 대충 12번("관중석이 편함"), 읽씹 0번, 핑계 13번, 야식 24번("24시 영업"). → 문구는 frontend-dev가 확정, QA 검수.

**6단계 — 별명 바꾸기(있으면 좋음)**: 후보 2~3개(T1·T2 바꿔 조합, 글자형↔상황형) 순환. 기존 ifplayer 버튼 재사용.

**금지 규칙(코드로 막기)**: 이름 뒤 외국어 접미사(델·데·디·뇨·니에스타·-비치 등) 생성 금지. 같은 이름+같은 답 = 같은 결과.

## ⑤ 문구 톤 가이드

### 원칙 7가지
1. **한 줄이 곧 콘텐츠**: 큰 제목 16자, 설명 30자 이내. 설명이 필요한 농담은 버림.
2. **"너답다"가 먼저**: 사용자가 고른 답에서 나온 구체 디테일(7시 12분, 알람 5개, 단톡 120개)을 그대로 씀. 친구가 보고 "ㅋㅋ 이거 완전 너"라고 할 문장.
3. **숫자·시간으로 구체화**: "자주 늦음" X → "후반 12분 입장" O.
4. **해축러 공감 디테일**: 새벽 4시 경기, 하이라이트, 추가시간, 교체, VAR, 오프사이드, 이적시장, 직관 후 목 쉼, 유니폼 n벌. 축구 모르는 사람도 대충 알아듣는 수준까지만.
5. **자기비하 대신 귀여운 반전**: "쓸모없음" X → "의욕 100, 체력 15". 공유하고 싶은 자조여야 함.
6. **유행어는 결과당 최대 1개, 검수된 것만**: 현재 사용 가능 후보는 '딸깍' 정도. 확신 없는 밈은 안 씀(난리자베스·야르·쌰갈·아쟈스는 대표 검수 전 사용 금지).
7. **반복 소재 제한**: 치킨·라면·퇴근·월요일·늦잠은 콘텐츠당 각 1회 이하.

### 금지 목록 (QA가 검색으로 점검)
- 억지 외국어 흉내: 이름 + 델/데/디/알레한드로/곤살레스/-니에스타/-비치/-뇨, "압둘 라면" 같은 국적 말장난
- 철 지난 밈: 럭키비키, 원영적 사고, 중꺾마/중꺾그마, 제라드-램파드, 헤어드라이어·물병(퍼거슨 그대로 복붙)
- 선수·감독 조롱, 월드컵 탈락 관련 감독 밈, 인종·국적 비하
- 외모(대머리 등)·성별 고정관념·정치·혐오 소재
- 근거 없는 "실제 통계"처럼 보이는 %: 쓰면 "재미용" 표기

## ⑥ 작업 순서 체크리스트 (담당: frontend-dev)

시간은 대략치(합계 약 6~7시간). 위에서부터 순서대로, **필수**만 끝나도 배포 가능하게.

**0. 준비 (10분)**
- [ ] 작업 브랜치 생성, 현재 `fun/index.html` 백업

**1. 공통 — 필수 (1시간)**
- [ ] `fun/og/default.png`(1200×630) 제작 후 `<head>`에 og:image(절대 URL)·og:url·og:title·og:description·`twitter:card=summary_large_image`
- [ ] 광고 빈 박스 숨김(승인 전)
- [ ] 결과 화면 공유 버튼 3개로 정리: 이미지 저장/공유(현행) · 결과 링크 복사(신규) · 링크로 공유(Web Share url, 신규)
- [ ] `share()` 문구를 결과 URL + "너는 뭐 나와?" 형식으로 교체

**2. 결과 URL — 필수 (1시간)**

## ⑦ 대표가 결정해야 할 것

1. **삭제·통합 승인**: `league` 삭제, `number`→이름 생성기 흡수, `nation` 허브 제외(9종 체제). 되돌릴 수는 있지만 공개 콘텐츠가 줄어드는 결정이에요.
2. **카카오톡 공유 SDK**: 카카오 개발자 앱 생성 → JavaScript 키 발급 → 사이트 도메인 등록이 대표 계정으로 필요해요(쿼터 내 무료). 하실지 여부. 이번엔 링크 미리보기 + 링크 복사로 대신해요.
3. **결과별 카톡 미리보기 제목(Pages Functions)**: "윤재의 축구 별명: 후반 재투입 윤재"처럼 링크 미리보기에 결과가 보이게 하려면 `functions/`에 파일 추가 + `_routes.json` 설정이 필요해요(무료 한도 안). 오늘 같이 할지, 다음에 할지.
4. **최종 문구 검수**: 이름 생성기 문구 풀과 해축 은어("HERE WE GO" 등), 구단 드립(토트넘 '희망회로', 아스널 '다음 시즌') 수위를 그대로 둘지.
5. **이름이 결과 링크에 그대로 보이는 것**: 현재 안은 이름을 URL에 평문으로 넣어요(닉네임 권장 안내 포함). 괜찮은지, 아니면 가려서(인코딩) 넣을지.
6. **희귀도 % 표기 여부**: 넣으면 공유가 늘지만 실제 통계가 아니라서 "재미용" 표기가 필요해요.
7. **배포 승인**: QA 통과 후 배포 직전에 한 번 더 확인받을게요.
