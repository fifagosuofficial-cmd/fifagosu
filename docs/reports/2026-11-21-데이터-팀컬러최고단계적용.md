# 팀컬러 선택 안 되던 문제 수정 + 최고 단계 기준 적용

- 작성: 데이터 개발자 / 프론트 개발자 (메인 세션)
- 날짜: 2026-11-21

## 원인
- 선수 카드의 "소속 팀컬러"는 `data/teamcolor/teamcolors.json`을 읽어 목록을 만드는데, 이 파일이 아직 한 번도 만들어지지 않았어요.
- 수집기(`crawler/teamcolor.py`)는 표(`<tr>`) 형태를 가정했지만, 실제 데이터센터 `/datacenter/teamcolor`는 카드형 `div.teamcolor_item` 목록이라 0건으로 파싱 → 저장이 건너뛰어졌어요.
- 국가 이름도 데이터센터에선 "대한민국, 국가대표"처럼 붙어 나와 이름 비교가 안 맞았어요.

## 실제 페이지 구조 (2026-11-21 확인, 844건)
- 각 카드: `.crests img`(아이콘) + `.num`(최고 단계 필요 인원) + `.name` + `.level`(최고 단계) + `.desc .item`(효과)
- 아이콘 경로로 종류 판별: `crests/.../l{클럽ID}.png` = 클럽(209), `countries/.../f_{국가ID}.png` = 국가(56), `tc_u_[b/s/g/p].png` = 강화 물결, `tc_u_c.png` = 초심자 가호(event), `4_l*.png` = 시즌·관계 특수 팀컬러(special)
- 예: 토트넘 홋스퍼 4단계·11명·전체+4/반응 속도+3/위치 선정+3, 대한민국(f_167) 4단계·11명

## 변경
1. `crawler/teamcolor.py`: 카드형 목록 파서 추가(우선 사용, 기존 표 파서는 예비). `clubId`/`nationId`/`id` 저장.
2. `tests/fixtures/teamcolor_cards.html` + 테스트 추가.
3. `site/assets/js/app.js`
   - 소속 팀컬러: **최고 단계 효과를 바로 적용**, "적용 인원" 칸 삭제
   - 강화 물결도 최고 단계 기준으로 통일, "조건 인원" 칸 삭제(강화 단계 조건은 유지)
   - 국가명 쉼표 앞만 비교 + 국가ID·현재 소속팀ID로도 매칭
