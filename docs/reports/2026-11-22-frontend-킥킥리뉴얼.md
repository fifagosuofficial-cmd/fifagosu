## 2. 구현 내용과 이유

### 2-1. 공통 엔진
- **og 메타**: `og:title/description/url/image(+width/height/alt)`, `twitter:card=summary_large_image`, `twitter:title/description/image`. Function이 이 태그들을 바꿔요.
- **SHARE_URL 고정**: `https://fifagosu.pages.dev/fun/`. `/fun/r/`에서 열어도 카드 하단이 `fifagosu.pages.dev/fun`으로 나와요(검토서 2-4 버그 수정).
- **카드 하단 문구**: "나도 해보기 · …" → "너는 뭐 나와? → fifagosu.pages.dev/fun" (모든 카드).
- **toBlob**: 결과 이미지를 `toBlob` + `createObjectURL`로 넣고, 바꿀 때 이전 URL을 해제해요(저사양 폰 메모리).
- **공유 버튼 3개**: 이미지 저장 / 결과 링크 복사 / 링크로 공유. 이름이 들어가는 name·duo에는 "링크에 이름이 들어가요".
  - 인앱(UA에 KAKAOTALK·Instagram·FBAN 등): "이미지를 길게 눌러 저장하세요" 안내, 링크 복사 때 입력창도 띄움.
  - 클립보드가 실패하면 링크가 선택된 입력창 + "길게 눌러 복사하세요". `navigator.share`가 없거나 실패하면 복사로 대체.
- **광고**: 승인 전에는 빈 박스를 숨겨요. 승인 후에는 결과 화면에서 위쪽 광고를 빼고, 공유 버튼과 "다른 테스트" 아래(adBot)에만 보여요.
- **허브**: 9종을 마스터플랜 ③ 순서·부제 그대로, 이름 생성기는 큰 히어로 타일(입력창 없음). "선수 873명" 같은 하드코딩 숫자 삭제.
- **숨김·별칭**: league·nation은 `hidden:true`(허브와 "다른 테스트" 추천에서 빠지고 `#/league`·`#/nation`은 그대로 열림). `#/number` → `#/name`(ALIAS).

### 2-2. 결과 링크 `/fun/r/?d=<base64url>` v1
- `b64e/b64d/parseD/mkLink`를 클라이언트에 두고, 같은 규칙을 Function에 복제했어요(파일 머리 주석에 "바꿀 땐 둘 다").
- 종류: `name`(이름+답변코드+k로 다시 계산), `duo`(A·B로 다시 계산), 유형형 `manager/fan/club`(결과키), `go`(ifplayer·balance·blur·price는 친구 결과 배너 + 시작 화면).
- club은 결과키에 %와 2위 구단을 넣었어요(`lfc78mil`). 키 하나로 같은 카드를 그리기 위해서고, 형식은 `^[a-z0-9]{1,10}$` 안이에요.
- 링크 주소는 그 사이트의 origin을 써요(운영 = fifagosu.pages.dev, 미리보기 배포 = 그 주소, 로컬 = localhost).
- `route()` 우선순위: ① `?d=` → 친구 결과(읽자마자 `history.replaceState`로 쿼리를 지워서 이후 해시 이동이 막히지 않게) ② 해시(+별칭) ③ 허브.
- 친구 결과 화면에는 "나도 해보기"(`/fun/#/앱`)가 있어요. duo는 "나랑 {A} 궁합 보기"를 누르면 친구 이름이 미리 채워져요(sessionStorage).
- 형식 오류는 허브로 가요. 다른 버전(v2)은 마스터플랜 6-2대로 **글자만 보여주고 "나도 해보기"**를 띄워요(8-3의 "v2 → 허브"와 표현이 달라서 6-2를 따랐어요).

### 2-3. Function `functions/fun/r/[[path]].js`
- `env.ASSETS.fetch('/fun/')` → HTMLRewriter로 `<head>` 맨 앞에 `<base href="/fun/">`(항상)를 넣고, `d`가 올바르면 og:title·og:description·twitter:title·twitter:description·og:url(요청 URL)·`<title>`을 바꿔요.
- 헤더: `Cache-Control: public, max-age=3600`, `text/html; charset=utf-8`.
- 예외가 나면 base만 넣은 원본을 내보내고, 그것도 실패하면 `/fun/?d=…`로 302를 보내요. 500은 내지 않아요.
- og 문구는 마스터플랜 6-4 표 그대로예요. 이름은 Function 안의 `callName`(20줄)으로 성을 떼요.

### 2-4. 이름 생성기 (마스터플랜 ④ 전체)
- 기존 문구 데이터(TPL/FIRST/MID/…/CHANT)는 전부 삭제했어요.
- 질문 10개·태그 8개(각 5회, `console.assert`로 검사), 성 떼기(성씨·복성), 합성 사전 42글자, 수식어·상황형·태그 한 줄 풀, 반전 12쌍, 근거 한 줄, 칩 3개, 등번호를 넣었어요.
- 계산 순서 4-5 구현: 동점이면 모순 쌍 우선, 그다음 시드. 16자 길이 검사와 대체 규칙 포함.
- 시드는 용도별로 나눴어요(`'kk-nick:v1|이름|코드'+'|t/p/w/m/l/s'`). "별명 바꾸기" 후보끼리 근거·칩이 일관되게 하기 위해서예요.
- 별명 바꾸기(있으면 좋음)도 구현: 기본 / T1·T2 바꿈 / 반대 방식. 링크에 `k`가 들어가요.
- 결과 카드는 ⑤ 레이아웃: 머리말, 큰 제목(최대 2줄·72px까지 축소), 부제, "왜 이 별명?" 박스, 칩, 유니폼 등판(이름+번호+한마디), 하단 1560px. 카드 밖에 "'윤재'로 불렀어요".
- 입력: 최대 6자, 한글·영문·숫자만(`cleanNm`). 입력칸에 "닉네임도 OK" 안내.
- 자동 점검용으로 `window.__kkNick`를 노출했어요(결과에는 영향 없음).

### 2-5. 기존 콘텐츠 수정
- **ifplayer(필수)**: 20 → 14문항(`>=12`), 코멘트 첫 문장만, 별명 띄어쓰기("두 개의 심장 알리송", "택배 기사 마르셀루", PRE_SP 표), 소개 문구의 20 → 14, go 링크 라벨 "{별명} {싱크로율}%".
- **duo(필수)**: 선수 콤비 비유(메시-수아레스·제라드-램파드 등) 전부 삭제. TIER를 [케미명, 한줄평] 짝으로 바꾸고 7-1 표 10개를 넣었어요. 기존 문구는 첫 문장만 남겼어요. 결과 링크 연결.
- **balance(필수 + 있으면 좋음)**: 대머리 문항 교체, 리프팅 반응 교체. "상위 1%" 문항은 금지어(`상위 `+`%`)라 "하나만 최고가 된다면: 동네 최강 vs 해설위원급"으로 바꿨어요.
- **manager(필수)**: 단점 "라커룸 방음 공사 필요". 금지어 `물병`이 보기에도 있어서 "물병이 날아다닌다" → "라커룸이 쩌렁쩌렁 울린다"로 바꿨어요.
- **있으면 좋음**:
  - price: 금액 ×10,000(억·조 단위, `won()`에 조 추가), 치킨 환산 다시 계산(만·억 마리), "숨은 원석" 문구.
  - club: 쏠림 보정(득표 ÷ 선택지 등장 횟수), 밀란 문구.
  - fan: 해시태그 2개 교체.
  - blur: 칭호 문구 2개 교체.
  - 유형형 3종은 친구 결과 링크용으로 "결과만 다시 그리기"(`show`)를 분리했어요.
- **number**: 코드 삭제(이름 생성기 등번호로 흡수). 옛 링크는 ALIAS로 연결돼요.
