## ① 핵심 요약 (3줄)

1. 요즘 한국에서 공유되는 테스트의 공통점은 **짧음(12~30문항) + 직설적인 유형명 + "너답다"는 친구 반응이 바로 오는 공감 디테일**이다. 결과 자체보다 "내 결과를 단톡방에 던졌을 때 대화가 시작되는가"가 핵심이다. (테토-에겐, SBTI)
2. 대표님이 지적한 '억지'의 원인은 **내용과 사용자 사이의 연결고리 부재**(윤재 델 졸리노 = 이름·답변·한국 축구 맥락 어느 것과도 무관)다. 해법은 **사용자가 입력한 것(이름 글자, 습관 답변)을 별명의 재료로 직접 쓰는 것**이다.
3. 공유는 "결과 카드 이미지 저장(9:16) + 결과 URL의 카톡 미리보기(OG) + 친구에게 '너는 뭐 나와?'" 3종 세트가 무료로 가능하다. 카카오톡 공유 API 자체도 쿼터 내 무료지만 JS 키와 도메인 등록이 필요하다. 다만 철 지난 밈과 특정 인물 조롱은 오히려 역효과이므로 피한다.

**공통 패턴 정리**

- **[사실]** 짧다 (12~30문항, 3분). 테토-에겐 12문항 앱, SBTI 30문항(MBTI 대비).

- **[사실]** 결과가 "고정된 나"가 아니라 "오늘의 나"라서 가볍게 다시 하고 다른 결과를 또 공유한다 (SBTI 보도: 기분 따라 결과가 달라질 수 있음).
- **[사실]** 연예인·친구를 유형에 대입해 추리하는 2차 콘텐츠가 확산을 이끈다 (테토-에겐).
- **[사실]** 정체성 프레임: MBTI 이후 "나를 설명하는 틀" 수요가 이어지는 중 (뉴닉, 한국경제 분석).
- **[추측]** 반전(예: 제일 멋진 유형이 아니라 약간 웃긴/한심한 유형)과 희귀도(%)는 "나만 이런 게 나왔다" 자랑/자조 공유를 만든다. SBTI 희귀 유형 언급이 근거지만 한국 사례 수치는 없음.
- **[추측]** 축구 테스트에서는 "내 몸에 새겨진 해축 습관"(새벽 경기, 직관 후 목쉼, 이적설 물고 늘어짐 등) 같은 공감 디테일이 MBTI식 일반 문장보다 훨씬 강할 것이다.

| **결과 URL 공유 + "나도 해보기"** | 결과를 `?r=...` 같은 파라미터로 URL화, 친구가 열면 결과 카드+"나도 해보기" 버튼 | 무료(정적 가능) | [추측] 설계. 단 **카톡/인스타 크롤러는 JS를 실행하지 않으므로**, 결과별 OG 태그를 서버(Cloudflare Pages Functions)가 HTML로 내려줘야 결과별 미리보기 이미지가 달라짐 [추측, 일반 웹 지식]. Functions 무료 한도 수치는 [확인 필요] |
| **친구 결과 비교** | 내 결과 + 친구 결과 URL 2개를 받아 "궁합/겹침/차이" 표시 | 무료 | [추측] 기존 '투톱 궁합'과 합칠 수 있음 |

## ⑤ 이름 별명 생성기 설계 제안 + 예시

### 5-1. 왜 '윤재 델 졸리노'가 재미없나 (분석)

1. **이름과의 연결이 0**: '윤재'에서 가져온 건 앞 두 글자뿐, '델 졸리노'는 어디서 왔는지 사용자가 설명할 수 없다. 사용자가 "아 이거 내 얘기네"가 안 된다.
2. **맥락 없는 외국어 흉내**: 스페인/이탈리아풍 이름을 붙이는 건 "외국 선수 이름처럼"이라는 한 번의 웃음(이미 흔한 패턴)밖에 안 준다. 설명이 필요한 농담은 공유되지 않는다.
3. **답변이 반영되지 않음**: 같은 이름이면 누구든 비슷한 결과 → 친구 것과 비교하는 재미 없음.
4. **한국어 말맛 부재**: 한국 MZ 웃음은 라임, 음절 늘이기, 초성, 상황 묘사의 구체성에서 나온다.

### 5-2. 설계 원칙 (구조)

별명 = **[답변에서 온 상황 수식어]** + **[이름 변형]** + **[포지션/축구 용어 한 방]**

- **이름 변형 규칙 (규칙 기반, API 불필요)** [추측]
  - 끝 글자 라임: 이름 끝 글자로 끝나는 단어/축구 용어(윤재→"~재" 계열: 재투입, 재경기), 받침 유무에 따른 라임 사전 준비
  - 이름 글자 쪼개기/초성: 윤재 → ㅇㅈ / "윤"+"재"를 각각 다른 단어로 풀기
  - 성 제외한 이름 두 글자 반복 ("재재", "윤윤") / 음절 늘이기 ("윤재애애")
  - 실존 선수 이름 **혼합은 가볍게**(예: 같은 글자가 겹칠 때만) — 억지 느낌이 큰 영역이라 비중 낮춤
- **답변 10문항 → 태그** : 시간(지각/칼퇴), 사교(읽씹/단톡 폭주), 먹기(야식), 승부욕(져도 다시), 새벽 경기, 체력, 거짓말(핑계), 돈(직관 티켓/유니폼), 폼(선수 사진 보정), 말투
- **태그 조합으로 문장 템플릿 선택**: 서로 모순되는 태그 조합이 오히려 웃김(예: 승부욕 높음 + 체력 바닥)
- 이름 + 태그 2개 이상일 때만 결과 생성, 결과마다 **"왜 이렇게 나왔는지" 한 줄**("지각 자주함 + 야식 = ...")을 보여주어 억지 느낌 제거

### 5-3. 예시 (제안, 모두 [추측]·조사자 창작. 실제 사용 전 대표님 검수)

## ⑥ 킥킥에 넣을 것 Top 5 / 빼야 할 것

### Top 5 (추천 순)

1. **이름+습관 질문 10개 별명 생성기 (개편안)** — 위 ⑤의 구조. 결과마다 "왜?" 한 줄 포함.
2. **"축구 SBTI" 짧은 유형 테스트 (12~20문항, 유형명 짧은 한 단어, 희귀도 표시)** — 예: "후반교체형", "VAR형", "벤치워머형" 등 (제안). 현재 '내가 축구선수라면?' 20문항을 줄여 유형명 중심으로 재설계.
3. **"우리 단톡방 포지션" 친구 초대/비교** — 결과 URL로 친구가 "나도 해보기" → 둘의 결과 비교(기존 투톱 궁합 개선). 바이럴 루프의 핵심.
4. **"해축러 공감 체크리스트" ('나 이거 다 해당돼' 체크 → 해축 중독 지수)** — 내쪼식 체크리스트 구조. 항목 문구는 실제 팬 검수 필수.
5. **공통 공유 인프라**: 모든 결과 9:16 카드 저장/공유 버튼 + 결과별 OG(카톡 미리보기) + (선택) 카카오 JS 공유 버튼.

### 빼거나 줄일 것

- **외국어 흉내 별명**(윤재 델 졸리노식) 및 이름과 관련 없는 랜덤 조합 — 즉시 폐기.
- **20문항 이상의 긴 테스트** — 문항을 10~20개로(또는 이름 생성기 10개 유지).
- **철 지난 밈**(럭키비키, 원영적 사고 등) 및 **의미 불분명 젠지어 남발**(야르/쌰갈/아쟈스는 검수 후 최대 1~2개).
- **감독·선수 조롱, 인신공격, 인종차별 연상 소재** (월드컵 탈락 후 밈 포함) — 광고 사이트 리스크 + 이미 식었을 가능성.
- **공유 포인트 약한 테스트는 통합/정리 제안 [추측]**: '내 몸값 이적료 환산', '내 등번호 뽑기', '몇 부 리그' 등은 결과가 "숫자 한 줄"이면 공유 동기가 약함 → 위 Top 5 형식(유형명+별명+한 줄 이유)으로 흡수하거나 하나로 합치기. 실제 12종별 공유율 데이터를 보고 결정 권장.
- **희귀도 퍼센트를 실제 통계처럼 표기** — 설계된 수치면 "재미용" 표기.
