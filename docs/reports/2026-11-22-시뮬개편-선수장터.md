- 예) `10~11강 확정 패키지` = `[26UP 11강 기회] 10~11강 확정 상자` 1개 + `[동일확률] 26UP Top Price 1435 (1~7강)` 3개

- 한계: `크리스탈 상점 참여권`, `삼지선다 정답 펜`처럼 **확률표가 없는 교환권**은 계산에서 빠져요(화면에 "확률 정보 없음 · 제외"로 표시). FC INFO는 참여권을 BP로 환산하는데, 환산 기준을 정하면 나중에 넣을 수 있어요.

## 3. FC INFO 효율/계산기 벤치마킹
FC INFO 메뉴: 강화 효율(TOP 10 · 예산으로 찾기 · 강화보호 기댓값 · 선수별 계산), 현질 효율(FC·마일리지·스페셜 상점), 아이템, 수수료 계산기.
가져온 아이디어와 피파고수식으로 바꾼 점:

| FC INFO | 피파고수 |
|---|---|
| 페이지마다 판매조건 줄 | **모든 탭이 같이 쓰는 '판매 조건' 바** + 최종 수수료 % 크게 표시 |
| 강화 효율 TOP 10 | **회수율 TOP 30**, 단계 칩(1→2 … 12→13), 줄마다 회수율 막대(1.00 기준선) |
| 예산으로 찾기 (효율적 / 인생 강화) | **남는 강화 / 한방 강화** 2열, 예산 빠른 버튼 |
| 선수별 계산 (기댓값·재료값·성공/실패) | 강화 시뮬 안에 **'이번 강화 손익'** 패널을 붙여 직접 눌러 보며 손익 확인. 게이지는 **1~5칸** |
| 재료값 = 같은 OVR 카드 × 5 | 우리 index.json에서 **OVR 이상 1강 최저가**를 자동 추정, 직접 입력도 가능 |
| 현질 효율 표 | **1,000 FC당 기대 BP** 순위, 패키지 구성품까지 반영, 누르면 팩 오픈으로 이동 |

화면 구성(카드형 탭, 민트 테마, 막대 그래프)은 피파고수 스타일로 새로 만들었어요.

## 4. 선수장터 게시판 (신규)
- 주소: `/trade/` (메뉴 '선수장터')
- 글쓰기: 팝니다/삽니다 → **선수 검색·선택** → 강화 단계 → **판매희망가/구매희망가**(억·만) → 닉네임·비밀번호 → 올리기
- 목록: 종류 필터, 선수 이름 검색, 거래 중만 보기, **피파고수 시세 대비 %** 표시, 비밀번호로 거래 완료/삭제
- 저장소: **Cloudflare D1(무료)**. 표는 첫 요청 때 자동 생성
- 안전장치: 비밀번호 PBKDF2 해시, IP는 해시만 저장(10분 3개·하루 20개 제한), 현금·계정 거래·외부 연락처·링크 문구 차단, 봇 함정 칸, 다른 사이트 요청 차단, 14일 뒤 숨김·30일 뒤 삭제
