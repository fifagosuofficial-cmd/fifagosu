# 전체 선수카드 시장 집계

## 적용 내용

- 급등·급락 목록과 시장지수는 랭커 사용 카드로 제한하지 않고, `data/list`에 수집된 전체 선수카드의 일별 가격 이력으로 계산해요.
- 1·5·8강별 최근 7일 변화를 비교하고, 3만 BP 이상인 유효 카드의 1강 변화율 중앙값을 시장지수로 표시해요. 유효 표본이 30장 미만이면 지수를 숨겨요.
- 인기 카드 시세는 계속 공식 1:1 상위 랭커 사용량으로 별도 집계해요.
- 홈에는 전체 카드 이력 누적 일수를 표시해요. 7일 비교에는 최소 8개의 날짜별 가격 기록이 필요해요.

## 전체 카드 이력 수집

- 데이터센터 선수 목록 크롤러가 수집한 일별 가격을 카드별 이력으로 저장해요. 랭커 순위는 전체 카드 급등·급락이나 시장지수 표본을 거르는 데 쓰지 않아요.
- 전체 카드의 과거 그래프를 한꺼번에 내려받는 방식은 선수별 개별 조회가 필요해 비효율적이에요. 현재 저장된 일별 이력은 2026-11-21부터 시작하며, 충분한 기간이 모일 때까지 홈에 누적 진행 상황을 보여줘요.
- 날짜별 크롤에서 일부 카드만 갱신되더라도 해당 카드 이력은 저장하고, 가격 양쪽 날짜가 확인되는 카드만 비교해요.
