# 홈 시장지수 7일 시세와 인기 카드

## 적용 내용

- FC온라인 데이터센터 `PlayerPriceGraph`에서 선수·강화별 일별 시세 그래프를 받아 최근 그래프 날짜부터 7일 전까지의 가격 8개만 보관하도록 했어요. 그래프 날짜는 연도 없는 `월.일` 형식이라 연도 경계도 보정해요.
- 매일 기존 수집 작업 끝에 전일 공식 1:1 상위 랭커 사용량을 읽고, 상위 100개 카드의 1·5·8강 그래프를 새로 받아요. 요청은 기존 데이터센터 클라이언트 간격(약 1.5초)을 사용해요.
- `급등·급락 TOP`은 최근 7일 가격 변화율로 다시 정렬해요. 100만 BP 미만 가격은 제외하고, 1강 유효 카드가 30장 이상일 때 카드별 변화율 중앙값을 시장지수로 표시해요.
- 홈 문구를 `인기 카드 시세`로 바꾸고, 표본 수와 사용량 기준을 함께 보여줘요.

## 사용량 표본 기준

- 표본이 충분하면 최근 7일간 정상 종료된 공식 1:1 경기의 `division ≤ 900` 선수 카드 사용 횟수를 우선 집계해요.
- 공식 데이터센터 선수 기록 검색은 등급별 필터 대신 전일 공식 랭킹 범위를 제공해요. 정확한 챔피언스 이상 경기 표본이 30종 미만일 때는 랭킹 1~1,000위 사용량으로 대체하고, 홈 화면에 그 기준을 표시해요.
- 랭킹 범위 조회가 실패하면 챔피언스 이상 경기 표본을 사용해요. 따라서 실제 등급 필터 표본과 랭킹 범위 표본이 섞여 표시되지 않아요.

## 실행 경로와 한계

- 새 수집 스크립트는 `crawler/market_history.py`이고 기존 매일 실행되는 `crawler/rating.py`에서 호출해요. 보호 파일인 `.github/workflows/crawl.yml`은 변경하지 않았어요.
- 상위 100개 카드 × 3개 강화 단계로 최대 300번의 가격 그래프 요청을 추가해요. 1.5초 간격 기준 약 8분이며, 차단 응답이 오면 진행분을 저장하고 그날 추가 요청을 멈춰요.
- 첫 성공 실행에서 공식 차트가 제공하는 과거 데이터를 읽어 7일 비교 기준선을 만들어요. 이후 같은 카드군을 하루 한 번 갱신해요.

## 출처 확인

- 공식 선수 상세 예시: https://fconline.nexon.com/DataCenter/PlayerInfo?n1Strong=1&spid=300207993
- 실제 응답에서 선수 기록 표와 강화별 가격 그래프 응답을 확인했어요.
