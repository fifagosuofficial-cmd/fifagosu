# 전적진단 자산 시세 데이터 개발 보고

## 변경 내용

- 기존 `data/market/all_card_history` 전체 카드 스냅샷만 재활용해 전적진단용 경량 시세 조회 파일을 생성한다.
- 외부 API·데이터센터 요청은 추가하지 않는다.
- 산출물:
  - `data/diag/market.json`: 기준일, 지원 강화, 요청 비교 기간, 확보 이력 범위
  - `data/diag/market-{spid % 200}.json`: 선수 카드별 강화 시세·등락률
- 카드별 강화 행 형식은 `[현재가, 1일%, 7일%, 30일%, 실제1일, 실제7일, 실제30일]`이다.
- 요청 날짜의 스냅샷이 없으면 그 이전의 가장 가까운 전체 스냅샷을 사용하고 실제 비교 일수를 함께 기록한다.
- 최신 가격·비교 가격이 없으면 `0`으로 만들지 않고 `null`로 저장한다.
- 같은 기준일 산출물이 이미 있으면 다시 만들지 않는다.

## 정확성 및 한계

- 현재 전체 카드 이력의 지원 강화 단계는 1·5·8강이다.
- 다른 강화 단계는 기존 선수 목록의 현재 시세를 사용할 수 있지만, 과거 등락률은 `데이터 부족`으로 표시해야 한다.
- 전체 목록 스캔이 한 번도 끝나지 않았으면 `waiting-full-scan` 상태를 반환하고 임의 데이터를 생성하지 않는다.
- 부분 수집 결과는 등락 산정 기준으로 사용하지 않는다.

## 실행 방법

기존 일일 수집의 파생 데이터 단계에 자동 포함된다.

```powershell
python crawler/derive.py --data data --no-meta
```

## 검증

```powershell
python -m pytest -q tests/test_derive.py
```

- 결과: `14 passed`
- 희소한 기록일의 실제 비교 기간, 누락 가격의 `null` 처리, 최신 가격이 없는 카드 제외, 동일 기준일 재실행 생략을 검증했다.
