# 전적진단 · 구단관리 고도화 프론트 개발 보고

## 구현 내용

- 기존 전적진단의 검색, 모드·경기 수 선택, 약점 진단, 세부 지표, 선수별 기록, 시간대별 득실, 슈팅 맵, 전체 경기 기록과 기존 경고 기준을 유지했다.
- 상대 출전선수 카드의 클럽·국가 소속을 경기마다 집계해 `승리 TOP 3`와 `패배 TOP 3`를 간략 표시한다. 3명 이상 겹친 소속, 2경기 이상 표본만 사용하며 실제 게임 적용 팀컬러가 아닌 추정치라고 화면에 명시했다.
- 최근 검색, 즐겨찾기, 내 구단, 마지막 조회 시각, 닉네임·모드·경기 수가 담긴 공유 링크를 추가했다. 개인 BP·구매가는 공유하지 않는다.
- 종합 리포트에 승률 변화, 최근 출전 스쿼드 추정 가치, 우수 선수, 우선 보강 선수를 표시한다.
- 기존 선수별 기록 표 오른쪽에 현재 시세, 24시간·7일 변동, 경기당 골·도움, 라인 내 순위, 실전 기여, 종합 평가, 교체 후보, 필요 BP를 확장했다. 포지션·최소 출전·추천 필터와 정렬, 고정 헤더·선수 열을 추가했다.
- 스쿼드 관리 탭은 가장 최근 1경기 실제 출전 선수와 누적 최다 출전 선수를 혼동하지 않게 기준을 표시하고, 라인별 건강검진과 보강 우선순위를 공통 평가 로직으로 계산한다.
- BP 자산관리 탭은 최근 출전 선수 시세 합계, 자산 비중, 1·7·30일 변동, 구매가·평가손익, 보유 BP·목표 가치를 제공한다. 누락 시세는 0으로 넣지 않고 합계에서 제외한다.
- 성장 기록은 같은 구단주·모드 진단을 브라우저 로컬 저장소에 일별 저장하고 이전 승률·득실·스쿼드 구성을 비교한다. 교체가 성적 변화의 원인이라고 단정하지 않는다.
- 랭커 비교는 현재 확보 가능한 같은 선수·같은 포지션 TOP 10,000 평균만 제공한다. 비슷한 예산 유저와 전체 스쿼드 비교는 데이터 부족으로 명시했다.

## 교체 추천 수정

- 기존 선수 강화등급을 모든 후보에 강제하던 방식을 제거했다.
- 강화 팀컬러가 있으면 후보마다 동빛 3강, 은빛 5강, 금빛 8강, 백금빛 11강 이상에서 예산·가성비에 맞는 강화단계를 선택한다.
- 물결이 없으면 1강부터 가격대에 맞는 강화단계를 후보별로 선택한다.
- 교체 대상이 속한 활성 팀컬러 중 클럽 팀컬러를 국가 팀컬러보다 우선 유지한다.
- 추천 팝업, 선수별 기록, 스쿼드 관리가 모두 같은 `recoFor` 결과(후보별 강화·가격·필요 BP)를 사용한다.

## 데이터·정확성 처리

- 시세 변동은 `data/diag/market-{spid%200}.json`을 지연 조회한다. 현재 지원되는 1·5·8강 이외 강화는 변동률을 `조회 불가`로 표시한다.
- 실제 비교 스냅샷 간격을 변동률 옆에 함께 표시한다.
- 표본 3경기 미만 선수는 실전 기여를 `평가 보류`로 표시한다.
- 시세·카드 상세·랭커 표본이 없으면 0이나 임의 수치를 만들지 않는다.
