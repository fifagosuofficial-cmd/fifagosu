# 급등·급락 기준 재조정 보고

## 변경 이유

선수 사용 횟수는 실제 거래량이 아니므로 가격 급등·급락의 원인이나 강도를 판단하는 기준에서 제외했다. 고정 현재가 하한도 임의 기준이므로 제거했다.

## 새 기준

- 시작가와 현재가가 모두 유효한 양의 정수
- 가격 관측 3회 이상
- 변동률 절댓값 3% 이상
- 같은 기간·강화 단계 전체 유효 카드 중 절대 BP 변동액 상위 20% 이상
- 신규 감지 후 2일 이내 카드는 초기 가격 불안정을 고려해 제외

두 조건을 통과한 카드의 변동률 순위와 절대 변동액 순위를 동일 비중으로 합쳐 시장 영향도를 계산한다. 동점은 절대 변동액, 변동률, 카드 ID 순으로 정렬한다.

## 표시 변경

- 급등·급락: 변동률과 절대 BP 변동액만 표시
- 인기 카드: 기존처럼 사용 횟수를 표시할 수 있음
- 홈 기준 문구: `변동률 3% 이상 · 절대 변동액 상위 20% · 관측 3회 이상`

## 데이터 비용

기존 일별 가격 이력만 사용하며 추가 API 요청이나 서버 비용은 없다.

## AI 스쿼드 아이콘 보완

선수 사진 옆 교체·삭제 버튼의 SVG가 일부 모바일 환경에서 보이지 않는 문제를 피하기 위해, 교체는 `↔`, 삭제는 `×` 문자 아이콘으로 변경했다. 색상뿐 아니라 기호로 기능을 구분하며 기존 접근성 이름과 툴팁은 유지한다.
