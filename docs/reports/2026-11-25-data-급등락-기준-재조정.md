# 급등·급락 기준 재조정 보고

## 변경 이유

선수 사용 횟수는 실제 거래량이 아니므로 가격 급등·급락의 원인이나 강도를 판단하는 기준에서 제외했다. 고정 현재가 하한도 임의 기준이므로 제거했다.

## 새 기준

- 시작가와 현재가가 모두 유효한 양의 정수
- 가격 관측 3회 이상
- 변동률 절댓값 3% 이상
- 같은 기간·강화 단계 전체 유효 카드 중 절대 BP 변동액 상위 20% 이상
- 신규 감지 당일과 다음 2일은 초기 가격 불안정을 고려해 제외

조건을 통과한 카드는 강화 단계 안에서 변동률 백분위 40%, 절대 변동액 백분위 40%, 최근 가격 3개의 방향 지속성 20%로 점수를 계산한다. 동점은 절대 변동액, 변동률, 강화 단계, 카드 ID 순으로 정렬한다.

## 표시 변경

- 급등·급락: 강화 단계, 변동률, 절대 BP 변동액, 최근 흐름 표시
- 인기 카드: 1강 시세와 사용 횟수 표시
- 홈 기준 문구: `전체 시즌·전체 강화 카드의 실제 시세 변동 기준`

## 데이터 비용

기존 일별 가격 이력만 사용하며 추가 API 요청이나 서버 비용은 없다.

## AI 스쿼드 아이콘 보완

선수 사진 옆 교체·삭제 버튼의 SVG가 일부 모바일 환경에서 보이지 않는 문제를 피하기 위해, 교체는 `↔`, 삭제는 `×` 문자 아이콘으로 변경했다. 색상뿐 아니라 기호로 기능을 구분하며 기존 접근성 이름과 툴팁은 유지한다.

## 검증

- Python 테스트 64개 통과
- JavaScript 테스트 57개 통과
- `app.js`, `squad.js` 문법 검사 통과
- 운영 데이터 기반 정적 빌드 성공

## 전체 강화 통합 순위 추가

- 시장 이력 저장 범위를 1·5·8강에서 1~13강 전체로 확대했다. 이미 수집한 카드 목록의 가격만 사용하므로 외부 요청은 늘지 않는다.
- 강화 단계별로 관측 3회, 변동률 3% 이상, 절대 변동액 상위 20%를 먼저 판정한 뒤 전체 강화 결과를 합친다.
- 최종 점수는 변동률 백분위 40% + 절대 변동액 백분위 40% + 최근 3개 가격의 방향 지속성 20%다.
- 같은 카드가 여러 강화 단계에서 움직여도 한 방향 순위에는 최대 2개까지만 노출한다.
- 전적 진단의 기존 1·5·8강 압축 데이터 구조는 별도 상수로 분리해 그대로 유지했다.
