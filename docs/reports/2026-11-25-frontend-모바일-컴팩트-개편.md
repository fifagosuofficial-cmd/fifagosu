# 모바일 메뉴·AI 스쿼드·전적 리포트 컴팩트 개편

## 변경 내용

- 모바일 상단 메뉴를 4열 2행 반응형 그리드로 고정하고 `선수 거래소`를 첫째 줄로 올렸다. 마지막 메뉴 하나만 셋째 줄로 떨어지지 않는다.
- AI 스쿼드 전체 폭을 1,040px, 생성 결과를 960px, 경기장을 900px로 제한했다. 폼·요약·보너스·선수 카드의 여백과 글자 크기를 화면 폭에 따라 줄였다.
- 긴 추천 기준 설명은 접근 가능한 접이식 안내로 바꿔 생성 전 첫 화면 높이를 줄였다.
- 최근 경기 흐름, 6개 핵심 지표, 스쿼드 가치·우수 선수·우선 보강을 하나의 `종합 구단 리포트` 카드 안에 합쳤다.
- 중복이던 리포트의 `최근 승률` 카드는 제거했다. 승률은 핵심 지표에 한 번만 표시된다.
- `최근 스쿼드 AI 개선 추천`, `내 진단 기록에 저장`은 아이콘과 짧은 라벨을 사용한 작은 보조 버튼으로 바꿨다. `title`과 `aria-label`은 유지했다.

## 검증

- `node --check site/assets/js/app.js site/assets/js/squad.js` 통과.
- 진단·스쿼드 Node 회귀 검사 45개 통과.
- `pytest` 컴팩트 UI·커뮤니티 회귀 검사 9개 통과.
- 데이터가 없는 상태의 정적 사이트 빌드 성공(95개 파일).

## 남은 확인

- 실제 모바일 Safari/Chrome에서 360px·390px·430px 폭의 최종 시각 점검이 필요하다.
- 실제 선수 데이터로 생성한 스쿼드는 선수명이 긴 경우 카드 안 줄바꿈 상태를 한 번 더 확인한다.
- 배포와 운영 반영은 진행하지 않았다.
