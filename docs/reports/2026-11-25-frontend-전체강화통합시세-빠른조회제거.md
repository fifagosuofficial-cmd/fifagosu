# 전체 강화 통합 시세·빠른 조회 제거

## 변경 내용

- 홈 급등·급락의 강화 단계 선택을 없애고 1~13강 결과를 한 목록으로 표시했다.
- 급등·급락 행에 강화 단계, 변동률, BP 변동액, 최근 흐름을 함께 표시하고 해당 강화 카드 상세로 연결했다.
- 시장 설명을 `전체 시즌·전체 강화 카드의 실제 시세 변동 기준`으로 정리했다.
- 인기 목록과 시장 흐름은 각각 `인기 카드 1강 시세`, `1강 시장 흐름`으로 구분했다.
- 전적 진단의 최근 검색 기반 `빠른 조회`만 제거하고 즐겨찾기와 진단 기록은 유지했다.
