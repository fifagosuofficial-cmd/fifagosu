# 급등·급락 기준·AI 스쿼드 아이콘 QA

## ① 결론

**배포 가능**입니다. 기존 시장 계산 경로가 제거되어 모든 데이터 상태에서 공통 시장 랭커를 사용하며, AI 스쿼드 문자 아이콘도 요구대로 구현됐습니다.

검증 결과:

- 대상 Python 테스트: 26개 통과
- `squad.js` 문법 검사 통과
- `git diff --check` 통과
- 변경분에서 API 키·토큰 노출 없음
- `.env`는 `.gitignore` 적용 확인

## ② 발견한 문제

| 심각도 | 상태 | 파일 위치 | 발견 내용 |
|---|---|---|---|
| 중 | 해결 | `crawler/derive.py:393` | 기존 500만 BP·사용 10경기 계산 경로와 관련 상수를 제거하고 `step_market()`이 항상 `step_ranker_market()`을 사용하도록 통합했다. |
| 하 | 정상 | `crawler/market_rank.py` | 공통 랭커에서는 사용 횟수 필터·가중치와 고정 가격 하한이 제거됐고, 3% 이상·절대 변동액 상위 20%·관측 3회 기준 및 관련 테스트가 확인됐다. |
| 하 | 정상 | `site/assets/js/squad.js`, `site/assets/css/squad.css` | 교체·삭제 버튼이 SVG 대신 `↔`, `×` 문자와 고대비 색상을 사용한다. `aria-label`과 `title`도 유지된다. |
| 하 | 해결 | `.qa-market-dist/` | 정적 QA 산출물을 확인한 뒤 작업 폴더에서 제거했다. |

## ③ 대표에게 드리는 3줄 요약

1. 새 급등·급락 계산은 사용 횟수 없이 변동률 3%와 절대 변동액 상위 20%를 적용하도록 잘 바뀌었습니다.
2. 보조 데이터 파일 유무와 관계없이 예전 500만 BP·사용 10경기 기준으로 돌아가지 않도록 계산 경로를 하나로 통합했습니다.
3. AI 스쿼드 교체·삭제 아이콘은 `↔`, `×` 문자로 바뀌어 빈 색상 버튼 문제를 해결했고 접근성 이름도 유지됩니다.
