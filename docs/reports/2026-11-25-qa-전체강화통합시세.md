- Python 전체 테스트: **64 passed**
- JavaScript 전체 테스트: **57 passed**
- JavaScript 문법 검사: `app.js`, `squad.js` 통과
- 운영 data 브랜치 기반 정적 빌드: 성공
- 실제 빌드 결과: 1일 급등·급락 각각 10개, 동일 spid 최대 2개, 급등·급락 내 사용 횟수 미표시 확인
- 모바일: 360·390·430px에서 가로 넘침 없음 확인
- 보안: 코드 내 실제 API 키·개인키 없음, `.env` 추적 파일 없음

요구사항별 확인 결과:

- 시장 이력은 1~13강을 저장하고, 전적 진단 압축 스키마는 기존 1·5·8강을 유지합니다.
- 강화별 관측 3회·변동률 3%·절대 변동액 상위 20% 필터와 40/40/20 점수, 신규 카드 3일 제외가 공통 함수에 적용됩니다.
- 급등·급락은 사용 횟수와 고정 현재가 하한을 필터·점수·동점 정렬에 사용하지 않습니다. 3만 BP 조건은 1강 시장지수에만 남아 있습니다.
- 전체 강화 통합 후 같은 spid는 목록당 최대 2개이며, 강화 선택 UI는 제거됐습니다.
- 행에 강화 단계·변동률·BP 변동액·최근 흐름이 표시되고, 인기 카드는 1강 시세, 시장 흐름은 1강 기준으로 구분됩니다.
- 전적 진단의 빠른 조회만 제거됐고 즐겨찾기·진단 기록은 유지됩니다.
- AI 스쿼드의 교체·삭제 아이콘은 `↔`, `×` 텍스트 아이콘과 접근성 라벨로 표시됩니다.
