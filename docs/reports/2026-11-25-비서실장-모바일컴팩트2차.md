# 피파고수 모바일 컴팩트 2차 개편 보고

## 작업 범위

- 전적 진단의 `피파고수의 한마디`를 최근 흐름 1문장과 최우선 행동 1문장으로 제한했다.
- 종합 구단 리포트를 승률, 최근 5경기, 경기당 득실, 스쿼드 가치, 우선 보강의 5개 핵심 항목으로 줄였다.
- 선수 교체는 10경기 이상 표본을 기본으로 하며, 반복 평점 부진과 랭커 열세 또는 충분한 동일 포지션 대안이 함께 있을 때만 `교체 검토`로 표시한다.
- 모바일 메뉴의 `강화·현질 효율`은 760px 이하에서 `강화·현질`로 한 줄 표시하며 접근성 이름은 원래 명칭을 유지한다.
- AI 스쿼드는 최대 폭 820px, 결과 760px로 줄이고 600px 이하 조건 폼을 1열로 전환했다. 입력 높이 44px, 선수 카드 반응형 폭, 경기장 최소폭 제거, 보너스·전체 능력치 접기를 적용했다.

## 급등·급락 순위 개선

기존 단순 등락률 정렬을 공통 `시장 영향도` 정렬로 교체했다. 추가 API 호출은 없다.

- 사용 10경기 이상, 가격 관측 3회 이상
- 500만 BP와 같은 강화·기간 후보 가격 하위 20% 중 높은 값을 가격 하한으로 사용
- 절대 변동액 100만 BP 또는 시작가 1% 이상
- 신규 감지 후 2일 이내 카드 제외
- 등락률에 현재 가격대와 사용량 가중치를 적용
- 같은 점수는 절대 BP 변동, 사용량, 카드 ID 순으로 정렬
- 화면에 등락률, 절대 BP 변동, 사용 횟수를 함께 표시

시장지수는 기존 3만 BP 유효 표본 기준을 유지해 급등락 필터 변경과 분리했다.

## 교체 판정 기준

- 경로 A: 기준 평점 미달 60% 이상 + 평점 차 0.20 이상 + 랭커 열세 2개 이상
- 경로 B: 두 선수 모두 10경기 이상 + 동일 포지션 대안 평점 +0.25 이상 + 승률 +10%p 이상
- 경로 C: 기준 평점 미달 70% 이상 + 평점 차 0.35 이상 + 랭커 열세 1개 이상
- 느낌표, 가격, 한 경기, 단일 지표만으로는 교체를 추천하지 않는다.
