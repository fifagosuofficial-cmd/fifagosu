판매 실수령 BP

최종 수수료율 = 기본 수수료 × (100% − PC방 − TOP CLASS − 쿠폰) 공식을 써요(FC INFO 수수료 계산기 기준). 정확한 값은 게임 안 판매 화면에서 확인해 주세요.

선수 교체 비용

강화 계산기 넥슨 공지 확률(26.4 기준)

실제 성공 확률 = 풀 게이지 확률 × 게이지 비율(넥슨 공지). 실패해도 단계가 유지된다고(등급 보호) 가정한 기대 시도 횟수예요. 실패 시 하락·복구 확률은 공지에 이미지로만 있어 반영하지 않았어요.

공식경기 등급

등급은 아래에서 위로 유망주 → 세미프로 → 프로 → 월드클래스 → 마스터 → 챌린저 → 슈퍼 챌린지 → 챔피언스 → 슈퍼 챔피언스 순이에요. 유망주~챌린저는 각각 3부~1부로 나뉘어요.

  • 유망주 3부 ~ 월드클래스 1부: 스테이지를 오르내리는 사다리 방식이에요. 체크포인트에 닿으면 그 아래로는 떨어지지 않고, 점수가 크게 떨어지면 방어전이 열려요.
  • 챌린저 3부 이상: 랭킹 점수로 정해져요. 챌린저 3부 2,200점 · 2부 2,350점 · 1부 2,500점 · 슈퍼 챌린지 2,650점.
  • 챔피언스 계열: 2,650점 이상에서 순위로 나눠요. 1~100위 슈퍼 챔피언스, 101~1,000위 챔피언스.
  • 시즌: 8~10주, 전반기·후반기로 나눠 반기마다 보상을 줘요. 챌린저 3부 이상은 반기마다 점수가 초기화돼요.
  • 주간 보상 포인트: 승 3점, 무 1점, 패 0점, 하루 첫 경기 5점.

출처: 넥슨 공식경기 업데이트 공지, 넥슨 Open API 등급 메타데이터

감독모드

  • AI가 경기를 뛰어요. 직접 조작하지 않으니 결과는 스쿼드(능력치·강화·체형)와 포메이션, 팀 전술, 개인 전술로 갈려요.
  • 상위권 전술 경향: 수비는 지속적 압박, 공격은 롱패스 빌드업과 공격적 팀 성향이 많이 쓰여요. 4-1-2-3 같은 포메이션과 제로톱 구성이 인기예요.
  • 선수 고르기 팁: 센터백 190cm 이상, 스트라이커·풀백 180cm 이상, 중앙 미드필더는 피지컬을 중시해요. 체형은 마른 체형보다 보통·건장이 낫다는 의견이 많아요. 약발은 조작 모드보다 덜 중요해요.
  • 순위 보상: 시즌 종료 시 200위 이내에 FC 보상. 최근 시즌 200위 컷은 약 4,400점대였어요.
  • 장기 미접속 감점: 경기를 96시간 하지 않으면 30점이 깎인다는 정리가 있어요.

피파고수 스쿼드 추천의 '감독모드' 설정은 위 신체 기준을 가산점으로 반영해요. 출처: 인벤 감독모드 전술 가이드, 인벤 감독모드 팁, FC INFO 감독모드 정리 (커뮤니티 자료)

강화

강화는 13강까지 있어요. 카드 색은 1~4강 브론즈(동카), 5~7강 실버(은카), 8~10강 골드(금카), 11~13강 플래티넘(백금카)이에요. 특정 강화 단계에서 특성 슬롯이 열려요. '다음 강화 성공'은 부스트 게이지가 가득 찼을 때 확률이에요.

팀컬러

  • 소속 팀컬러(클럽·국가): 같은 팀 선수가 3·6·8·11명일 때 4단계로 보너스가 커져요. 일부만 같아도 그 선수들에게 적용돼요.
  • 특성 팀컬러: 듀오·트리오(2~4명), 전설의 스쿼드(5명), 유럽 대항전·국제 대회 진출 스쿼드(8명) 등. 소속 팀컬러와 둘 중 하나를 골라요.
  • 강화 팀컬러: 강화 단계가 높은 선수가 5명·8명 이상이면 모든 능력치가 올라요.

시즌과 선수 이미지

  • 같은 선수도 시즌마다 다른 카드예요. ICON, TOTY, TOTS, UCL, LIVE처럼 시즌에 따라 능력치와 가격이 달라서, 피파고수는 선수 이름 앞에 항상 시즌 배지를 붙여요.
  • 선수 고유 ID(spid) = 시즌 ID × 1,000,000 + 선수 번호. 넥슨 Open API의 시즌 메타데이터(seasonid.json)에 시즌 이름과 공식 시즌 이미지 주소가 들어 있어요.
  • 선수 얼굴·시즌 이미지는 넥슨 Open API의 '이미지 정보 조회'로 제공돼요. 피파고수는 이 공식 이미지를 그대로 표시해요. 이미지를 불러오지 못하면 시즌 이름 배지로 대신 보여줘요.

출처: 넥슨 Open API 시즌 메타데이터, 이미지 정보 조회 문서

급여·이적시장

  • 급여: 급여 상한은 310이에요(2026년 6월 25일 업데이트로 300에서 상향, PC·모바일 공통). 부족하면 골키퍼·풀백에서 급여를 아끼는 경우가 많아요.
  • 판매 수수료: 최종 수수료율 = 40% × (100% − PC방 30% − TOP CLASS 20% − 쿠폰). 예를 들어 셋 다 적용하고 쿠폰 30%면 40% × 20% = 8%예요.
  • 수수료 쿠폰: 2026년 6월 개편으로 한 번에 몰아서가 아니라 매주 점검 후 접속할 때 지급돼요.
